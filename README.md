# 💊 Medical Cost Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Healthcare](https://img.shields.io/badge/Healthcare-Regression-blue.svg)

## 📖 Overview

Regression model to predict individual medical insurance costs based on personal attributes including age, BMI, smoking status, and region. Provides cost estimation for insurance planning.

## 🎯 Objectives

- Predict medical insurance costs
- Identify cost drivers
- Risk-based pricing insights
- Healthcare expense analysis

## 🛠️ Tech Stack

- Scikit-learn (Linear, Ridge, Random Forest)
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Medical-Cost-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features

- Age, BMI, Children
- Smoking status (major factor)
- Gender, Region
- Medical history
